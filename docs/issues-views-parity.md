## Workspace Views

Hoja Workspace Views now exposes `/workspace/views/issues` and `/workspace/views/projects` with tabs, compact header, New view draft, empty state and actual browser-local saved entries, rather than presenting the old issue dashboard as the root. The route selects kind and saved entries from workspace-keyed `hoja_saved_views_<orgId>` (`frontend/src/main.tsx` `ViewsPage`), with kind tagging for projects while legacy untagged views remain issue views. New drafts take name, search, status, Cancel/Create and show loaded match count; attempts to duplicate a local view name show an error. Favoriting a local view stores a local favorite flag; `/workspace/favorite-views` is now a scoped Favorites page rather than an unavailable placeholder. These are **browser-local** views, not shared server views, and loaded issue/project counts may be incomplete. Existing saved views were not deleted. At t1 Issues empty matched Linear's empty reference, Projects tab navigated distinctly to `/workspace/views/projects`, Create new view opened a draft and Cancel returned to Issues; Favorites showed an honest empty state. No external Linear view was created. Browser storage rejection remains untested; a locally created project view filtered ENG-2 to one issue and retained its title/filter after direct reload.


## Sidebar

The historical two Views labels were not duplicate routes: Workspace Views linked `/workspace/views`, Favorites Views linked `/workspace/favorite-views`. The latter is now explicitly **Saved views** and uses the actual browser-local favorites screen. Under each real team name, Hoja now shows Home, Issues, Cycles, Projects and Views links (`frontend/src/main.tsx` sidebar nav around line 59), rather than a bare team button. Home routes to the team home; Issues to the existing team issue board; Cycles and Projects reuse real workspace views (not fictional team-scoped copies); Views reaches workspace browser-local issue views. The sidebar's global More group remains for Board/Cycles/Members/Settings, unlike Linear's workspace More, because removing those real destinations would reduce access. Routes use buttons and keep keyboard focus; the nested links truncate long labels, and at 390px the document has no horizontal overflow. Original t1 sidebar showed Saved views and team sublinks; clicking team Views reached `/workspace/views/issues`. A collapsed-team control and true team-only view scope are not yet implemented; do not claim 1:1 sidebar parity.
